Database Lokal Belum Terdeteksi

Aplikasi sedang berjalan dalam Mode Database Lokal (Offline) agar semua data tersimpan di laptop Anda sendiri tanpa internet.

Langkah Mengaktifkan Database di Komputer Ini:
  1. Buka aplikasi XAMPP Control Panel di laptop Anda.
  2. Klik tombol Start pada baris Apache.
  3. Klik tombol Start pada baris MySQL.

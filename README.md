# Jurnal Guru Digital & LMS - Aplikasi Windows Desktop (.exe)

Aplikasi desktop mandiri berbasis Windows untuk **Jurnal Guru Digital & LMS Kurikulum Merdeka**.

---

## 🚀 Cara Menjalankan Aplikasi Langsung (Mode Cepat)
Cukup klik 2x file:
👉 **`BUKA_APLIKASI.bat`**

Aplikasi akan otomatis menginstal dependensi (hanya di awal) lalu membuka jendela aplikasi desktop mandiri.

---

## 📦 Cara Membuat File Installer `.exe` (Untuk Dibagikan ke Guru Lain)
Cukup klik 2x file:
👉 **`BUILD_INSTALLER.bat`**

Setelah proses selesai, buka folder **`dist/`**. Di dalamnya terdapat:
1. **`Jurnal Guru Digital Setup 1.0.0.exe`** : Installer resmi untuk diinstal di komputer/laptop Windows manapun (lengkap dengan shortcut Desktop & Start Menu).
2. **`Jurnal Guru Digital 1.0.0.exe`** : Versi Portable (bisa langsung dijalankan dari Flashdisk tanpa perlu instalasi).

---

## ⌨️ Shortcut Keyboard Aplikasi
- **Ctrl + 1** : Dashboard Jurnal Guru
- **Ctrl + 2** : LMS Siswa
- **Ctrl + 3** : Kelola Bank Soal & Ujian
- **Ctrl + 4** : Portal Modul Ajar (Share)
- **F5** : Muat Ulang (Reload)
- **F11** : Layar Penuh (Fullscreen)
- **Alt + Left** : Kembali (Back)
- **Alt + Right** : Maju (Forward)
- **Alt + Home** : Beranda Utama
- **Ctrl + Plus / Minus** : Zoom In / Zoom Out
